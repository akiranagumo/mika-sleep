# SLEEPLESS 将来構想：アカウント・長期記憶・相談役・サブスクリプション

作成日：2026-11-07
状態：将来構想。未実装・未課金。

## 事業ビジョン
SLEEPLESS for MEN / for WOMEN を、単なる睡眠導入音声アプリではなく、利用者ごとに好みや過去の相談内容を適切に覚え、夜の話し相手や日常の相談相手になる継続的AIコンパニオンへ発展させる。

## 実装ロードマップ
1. 現在のリアルタイム音声・文字・おまかせ添い寝の会話品質改善、ミカ／AKIRA選択UIの安定化。
2. メール等のアカウント登録・ログイン、プロフィールの安全な保存、複数端末同期。
3. ユーザー同意に基づく長期記憶：趣味、好み、重要な出来事・相談の要約などを構造化して記録。履歴/記憶の表示、訂正、削除、記憶オフ機能。
4. 相談役機能：仕事、生活、恋愛、日々の気持ち、睡眠習慣への寄り添い。医学・心理療法・緊急支援を代替しない。危機対応・専門家紹介導線。
5. 無料体験と月額サブスク：利用時間・機能制限、決済、領収書、解約、利用枠表示。利用原価（ElevenLabs音声/LLMの分単位料金）を検証して価格を決める。

## 重要な設計原則
- 恋人のような演出はあっても、AIであることを明確に表示し、本人の人間的関係を置き換えると誇張しない。
- 個人的・機微な相談の保存は明確な同意制。データ最小化、アクセス制限、通信・保存時の暗号化、削除、漏えい対策、利用目的・保持期間の説明。
- 利用者の入力した「覚えてほしいこと」と自動要約を区別する。AIによる推測を本人の確定情報として記憶しない。
- 課金開始前に課金条件、上限、料金、キャンセル、返金、プライバシーポリシーと特商法表示など、日本向けサービス要件を確認する。
- 一人で孤立する方向に依存を誘導しない。精神的危機には人間の支援・専門機関の案内を提供する。
- 将来の男女両版で共通アカウントを目指す。キャラクター別会話の記憶共有は利用者が選択。
- AKIRAは本人をもとにしたAIキャラクター。本人とリアルタイムで通話していると誤解させない。
